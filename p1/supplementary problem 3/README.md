# GreenLeaf Organics Pvt. Ltd. — Semantic HTML5 Homepage

## 1. Project Objective
This project is developed as part of **ITUS102: Web Technology Framework (Practical 1)** to understand web architecture fundamentals by designing a semantic HTML5 homepage for **GreenLeaf Organics Pvt. Ltd.**

The primary goals of this project are to:
- Build a well-structured, accessible, and SEO-friendly webpage using HTML5 semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>`).
- Include essential webpage components such as company profile, products/services, featured banner, contact information, metadata, and favicon.
- Validate the HTML markup using the W3C HTML Validator.
- Manage source code versioning and collaboration using Git and GitHub.

## 4. Steps to Execute the Webpage Locally

### Option 1: Clone from GitHub
1. Open your terminal or Command Prompt.
2. Clone the repository:
   ```bash
   git clone [https://github.com/Dhveet/greenleaf-organics.git](https://github.com/Dhveet/greenleaf-organics.git)
   ```
3. Navigate into the project directory:
   ```bash
   cd greenleaf-organics
   ```
4. Open `index.html` directly in Google Chrome, Mozilla Firefox, or Microsoft Edge.

### Option 2: Run Using VS Code Live Server
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension (by Ritwick Dey) if not already installed.
3. Right-click `index.html` and select **Open with Live Server**.
4. The webpage will launch automatically in your default browser.
